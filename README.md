# 🛡 Advanced URL Security Analyzer

A client-side URL security analysis tool designed to detect phishing and malicious URL patterns using heuristic rules and ML-style confidence scoring.

This project is fully static and optimized for deployment on **GitHub Pages**.

---

## 🚀 Live Demo
👉 https://USERNAME.github.io/REPO_NAME/

---

## 🔍 What This Tool Does

✔ Validates URL structure  
✔ Detects phishing patterns (`@` symbol misuse)  
✔ Identifies IP-based URLs  
✔ Flags suspicious keywords  
✔ Detects brand impersonation  
✔ Generates ML-style confidence scores  
✔ Provides explainable feature importance  

All analysis is performed **entirely in the browser**.

---

## ⚠️ Limitations (Important)

This project runs in **client-side only mode**.

The following features are **intentionally not included**:

- ❌ WHOIS domain age lookup  
- ❌ VirusTotal integration  
- ❌ Backend API routes  
- ❌ Server-side processing  

These features require server infrastructure and are not compatible with static hosting environments like GitHub Pages.

---

## 🧠 Why Client-Side?

This architecture ensures:

- No API keys exposed
- No backend costs
- No CORS issues
- Instant analysis
- Fully static deployment

This design is ideal for:
- Portfolio demonstrations
- Educational use
- Security research showcases
